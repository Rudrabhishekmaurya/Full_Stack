# Netflix Clone

A responsive Netflix-inspired landing page built using frontend web technologies.

## Features
- Responsive design for desktop and mobile
- Hero section with background overlay
- Navigation bar with language & sign-in buttons
- Animated FAQ section
- Interactive hover effects
- Embedded video section
- CSS animations and media queries

## Technologies Used
- HTML5
- CSS3
- JavaScript

## What I Learned
Through this project, I practiced:
- Flexbox
- CSS Grid
- Positioning
- Responsive design
- CSS animations
- Media queries
